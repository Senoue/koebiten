### `10sec Go`の説明

`10sec Go`は、TinyGoとkoebitenを使用して作成されたゲームです。

基本的なゲームの概要は以下の通りです：

- **操作方法:** ロータリーボタンをクリックでスタート、3秒カウントダウン後に、キーボードを連打します。
- **ランキング表示:** ロータリーボタンを左右に回転させることで、表示内容を切り替えることができます。これにより簡単に自分の記録と全体のランキングを確認することが可能です。
- **連打数測定:** 10秒間カウントダウン中の連打数をカウントします。
- **制限事項:** 10秒間以外はカウント対象外となります。
- **目的:** 高い連打数を記録し、ロータリーボタンを使用してランキングを表示します。上位3位までの連打数が表示されます。

#### ゲームの特徴

1. **シンプルな操作性：**
    ユーザーはただキーボードを連打するだけという、直感的でシンプルな操作を提供します。

2. **チャレンジングな要素：**
    連打速度と持続力の両方が試されるため、非常にチャレンジングな体験となります。さらに10秒間の制限時間があることで緊張感も加わります。

3. **軽量グラフィックス：**
    TinyGoとkoebitenの組み合わせにより、軽量かつ楽しいグラフィックスが提供されます。

4. **リプレイ性：**
    自分の記録を更新するという目標があり、ユーザーは何度でもゲームを再プレイしたくなるでしょう。
